# Android vertical slice

The first phone interaction is now intentionally small:

- NativeActivity, no application DEX;
- EGL + OpenGL ES 2;
- one central cube;
- six colored ribbons generated by the host-tested semantic field;
- fixed camera;
- direct one-finger body grab;
- horizontal drag changes the signed, unwrapped physical spin angle;
- one short-screen-width drag corresponds to one 2π turn;
- release preserves the current lifted state.

Touch begins a body grab only inside a generous screen-space disk around the
projected cube. Touches elsewhere do not change the spin state. Camera gestures
are deferred rather than conflated with object rotation.

## Ownership

`spinor_android.c` owns:

- NativeActivity lifecycle;
- EGL surface/context lifetime;
- Android pointer IDs;
- converting captured horizontal pixel motion into a signed angle increment;
- saved physical-angle state.

`spinor_renderer.c` owns:

- GLES resources;
- fixed view/projection;
- converting semantic ribbon/cube geometry to GPU buffers;
- colors and drawing.

`../native/` owns:

- Spin(3) / SO(3) distinction;
- 0 / 2π / 4π state;
- ambient contraction field;
- six-ribbon mesh generation.

No contraction equation or ribbon interpolation is duplicated in the Android
event handler.

## Build

The leaf build is ABI-parameterized. Device/ABI policy remains in Cat Food and
paired A1/C67 orchestration belongs in Flexible Pipes.

Build one native library:

Set `ICK_ROOT` to the qualified installed stage for that ABI, or `ICK_CC`
to its compiler driver. See the [producer record](../notes/division-migration.md)
for the exact shared compiler pin and the ICK/NDK boundary.

```sh
ANDROID_ABI=armeabi-v7a \
ANDROID_NDK_HOME=/absolute/android-ndk-r27c \
bash android/build-native.sh
```

Package it through the canonical `isomorphisms/android-NDK` packager:

```sh
export ANDROID_NDK_CHECKOUT=/absolute/android-NDK
export SPINOR_KEYSTORE=/absolute/dev.keystore
export SPINOR_KEYSTORE_TYPE=JKS
export SPINOR_KEY_ALIAS=...
export SPINOR_STORE_PASSWORD=...
export SPINOR_KEY_PASSWORD=...
export SPINOR_EXPECTED_CERT_SHA256=...

ANDROID_ABI=armeabi-v7a bash android/build.sh
```

Use Cat Food's target profile to choose the ABI. Do not encode device hardware
facts in this repository.
